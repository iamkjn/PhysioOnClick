# Outreach & Guest Post Pitches — PhysioOnClick

Ready-to-send drafts. Fill in the `[bracketed]` fields, keep everything else as-is unless it doesn't fit the recipient. Send from `hello@physioonclick.co.uk`. Keep a simple log (site, date sent, reply y/n) so you don't pitch the same site twice.

## Practical notes

- **Don't mass-blast identical text** — swap in a real detail from the recipient's site each time (marked `[specific...]` above). Google and recipients both notice templated spam.
- **Realistic reply rate**: guest post pitches (1) typically land 5-15% replies in health/wellness niches; resource outreach (2) tends higher since you're not asking for editorial work from them.
- **Track what you send** — a simple spreadsheet (site, contact, date, template used, response) avoids double-pitching and tells you which angle works.
- **A backlink from a genuine guest post or resource link is worth far more than a directory listing** — prioritize these over further directory signups.
