# PhysioOnClick -- exercise & self-check image prompt sheet

_Generated 2026-09-09. 175 exercise illustrations + 49 self-check test photos._

## How to use this

- Generate one image per entry. **Save it as `<id>.png`** -- the id is the bold code at the start of each entry (e.g. `ex-55.png`, `test-full-can-3.png`). The filename is how the site matches the image to the exercise, so it must be exact.
- Square output, roughly **1024 x 1024**, on a plain pale background.
- **Do not ask for any logo, wordmark or caption.** The PhysioOnClick footer band is added afterwards by a separate step.
- Two different looks, kept separate below: the **exercise illustrations** are a clean anatomical-textbook drawing; the **self-check test photos** are realistic photographs of one consistent model.
- Try to keep the **same figure, clothing and background across a whole section** so a page of thumbnails reads as one set.
- Hand the finished PNGs back in one folder. They are reviewed by the physiotherapist, then uploaded. Until an image is uploaded the site shows a placeholder -- nothing breaks if some are missing.
