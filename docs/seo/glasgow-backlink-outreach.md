# Glasgow backlink outreach targets

Researched 2026-10-06. Nothing has been sent. Every URL below was checked with an automated HTTP request on that date:
- **200**: the page loaded.
- **403 (bot-blocked)**: the site turned the script away, but search results show the page exists. Open it in a browser before you use it.
- **Contact via page**: no separate contact URL was confirmed, so use the details on the listed page.

**Realism key:** H = could plausibly add a resource link. M = possible if the asset is clearly free and non-commercial. L = unlikely to link to a private practice. Approach only for awareness or a listing.

Ground rules for every approach:
- Offer the **free** assets: `/exercises`, the embeddable cards `/embed/exercises/<slug>`, and `/guides`, e.g. `/guides/nhs-physio-waiting-times-scotland`.
- Never ask for a link to the booking pages.
- Never claim an NHS partnership or referral route. The practice does not work alongside the NHS.

I've also written plain-English guides, including one on NHS physio waiting times in Scotland: https://physioonclick.co.uk/guides/nhs-physio-waiting-times-scotland. There's no sign-up and no charge.

If you think these would help your members, you'd be welcome to share them or add them to a resources page. I'd also be happy to give a free, no-sales talk at a meeting on keeping active at home.

No worries if it's not a fit.

Best wishes,
[Owner name]
